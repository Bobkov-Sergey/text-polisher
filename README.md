# Text Polisher

Расширение для Google Chrome, которое мгновенно перефразирует выделенный текст в официальный корпоративный стиль. Работает в любых полях ввода (`textarea`, `input`) и визуальных редакторах (`contenteditable`).

## Возможности
- Добавляет пункт «Перефразировать в официальном стиле» в контекстное меню браузера.
- Использует бесплатный [Groq API](https://groq.com) (модель llama-3.1-8b-instant).
- API-ключ хранится локально в настройках расширения.
- Не собирает и не передаёт пользовательские данные.

## Установка
1. Скачайте ZIP-архив репозитория: кнопка **Code** → **Download ZIP**.
2. Распакуйте архив в удобную папку.
3. Откройте Chrome, перейдите на страницу `chrome://extensions/`.
4. Включите **Режим разработчика** (справа вверху).
5. Нажмите **Загрузить распакованное расширение** и выберите папку с файлами.
6. Перейдите в настройки расширения (правая кнопка по иконке → Параметры).
7. Вставьте ваш API-ключ Groq (получить бесплатно на [console.groq.com/keys](https://console.groq.com/keys)).
8. Готово! Выделите текст в любом поле, нажмите правую кнопку мыши и выберите «Перефразировать в официальном стиле».

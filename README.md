# Text Polisher

Расширение для Google Chrome, которое мгновенно перефразирует выделенный текст в выбранном стиле.

## Что нового в версии 2.0
- Плавающая кнопка при выделении текста (как в Grammarly)
- Предпросмотр при наведении или по зажатому Ctrl/⌘
- Контекстное меню с текущим стилем
- Индикатор выполнения (прогресс-бар)
- Звуковой сигнал при завершении (опционально)
- История перефразирований с поиском, избранным и экспортом (CSV/JSON)
- Статистика использования
- Бейдж с количеством перефразирований за сегодня
- Popup с быстрой статистикой
- Поддержка Groq, OpenAI, DeepSeek, Gemini
- Адаптивная тёмная тема

## Установка
1. Скачайте ZIP-архив [text-polisher-v2.0.zip](text-polisher-v2.0.zip) из этого репозитория.
2. Распакуйте архив в любую папку.
3. Откройте Chrome, перейдите на `chrome://extensions/`, включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку.
5. Введите API-ключ в настройках расширения (бесплатный Groq — [console.groq.com/keys](https://console.groq.com/keys)).
